Pending Order Management

ShopEase maintains a singly linked list of pending orders. An order is removed based on its position counted backward from the most recently placed order.

Problem Statement

An online shopping application maintains a linked list of pending orders. Remove the nth node from the end of the linked list in one pass.

Time: O(N) Space: O(1)

Two-Pointer Algorithm (One Pass)

1 Create a dummy node pointing to head
2 Set both fast and slow to dummy
3 Advance fast by n+1 steps
4 Move both pointers until fast == NULL
5 Delete slow.next — that's the nth from end
